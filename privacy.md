# Privacy policy

**Erlang C Staffing Planner**

*Last updated: 27 August 2026*

## Summary

This visual processes your data entirely inside Power BI, on the device where
the report is open. It collects nothing, stores nothing, and transmits nothing.

## What the visual accesses

Only the fields you map into it: interval, contact volume, average handle time,
and optionally scheduled agents and queue name. It reads them to perform the
staffing calculation and draw the chart.

## What it does with that data

The data is held in memory for as long as the visual is rendered, and discarded
when the report closes. It is not written to disk, to browser storage, to
cookies, or anywhere else.

## What is transmitted

Nothing. The visual makes no network requests of any kind. It declares no
web-access privileges in its capabilities, which Power BI enforces at runtime,
and the absence of external requests is verified as part of Microsoft's
certification audit.

## Analytics and telemetry

None. We receive no usage data, no diagnostics and no error reports from the
visual.

Aggregate information about listing views, purchases and licence assignments is
available to us through Microsoft Partner Center. That is generated by
Microsoft Marketplace rather than by the visual, and is governed by Microsoft's
own privacy terms.

## Licensing

Where a licence applies, the visual asks Power BI which service plans are
assigned to the current user. That check happens between Power BI and Microsoft
using Microsoft's Licensing API. We receive no personal data from it — the
visual sees only whether a usable plan exists.

## Third-party components

The visual uses open-source components published by Microsoft for building
Power BI visuals. None of them transmit data externally.

## Children's data

The visual is business software and is not directed at children.

Material changes to this policy will be published on this page with an updated
